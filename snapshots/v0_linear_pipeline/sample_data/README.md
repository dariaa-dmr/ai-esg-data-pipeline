# Synthetic sample data

All companies, identifiers, domains, addresses, coordinates, employee counts, and financial values in this folder are synthetic. They are provided only to demonstrate CSV parsing and the linear pipeline interfaces.

- `input/sample_source.csv` — twelve-column source file.
- `output/sample_clean.csv` — splitter output.
- `output/sample_dirty.csv` — header-only dirty output for this fully repairable sample.
- `output/sample_final_active.csv` — compact example of normalized active output after enrichment and geocoding.

The INNs use deliberately non-production test patterns and must not be used for registry lookup.
